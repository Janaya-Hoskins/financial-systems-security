# Financial Systems Security Work Samples

Worked examples of financial systems security for billing and ERP applications: SOX ITGC testing, segregation of duties, access reconciliation, security monitoring and incident response, and security review of system changes.

**Live site:** https://janaya-hoskins.github.io/financial-systems-security/

> **All data is synthetic.** Northwind Holdings is a fictional company. Every person, account and transaction is generated by `scripts/generate_synthetic_data.py` with a fixed seed. Nothing in this repository is a record of any employer's systems, people or findings. The methods reflect my work supporting SOX-aligned access and SoD controls on Oracle CC&B and SAP FI/CO at Exelon, federal security operations at the Social Security Administration, IAM investigations at AWS and access governance at CVS Health.

## Contents

| Page | What it shows |

| [SOX ITGC Control Testing Workpaper](sox-itgc-workpaper.html) | Full-population tests of user access lifecycle, SoD on billing adjustments, and privileged/emergency access; design vs. operating effectiveness; remediation tracking |
| [SoD Matrix](sod-matrix.html) | Conflict rules for 12 financial and administrative roles, tested per person across all of their accounts |

| [Incident Case File](incident-case.html) | Alert-to-root-cause investigation of self-approved, off-hours billing credits |
| [Change Security Review](change-security-review.html) | Security impact review of a billing platform upgrade with go-live conditions |
| [Risk & Control Matrix](risk-control-matrix.html) | 14 access, change and operations ITGCs mapped to SOX/COSO and NIST SP 800-53 |

## Repository layout

```
data/      synthetic inputs (HR roster, accounts, role grants, adjustments, logs)
scripts/   generator, analysis scripts and site builder (Python standard library only)
sql/       the same control tests in SQL, plus a Splunk SPL detection rule
output/    results written by the analysis scripts
assets/    site stylesheet
*.html     GitHub Pages site
```

## Reproduce

```bash
python scripts/generate_synthetic_data.py
python scripts/reconcile_access.py
python scripts/sod_check.py
python scripts/incident_timeline.py
python scripts/build_site.py
```
