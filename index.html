Financial Systems Security Work Samples

Worked examples of financial systems security: ITGC/SOX testing, segregation of duties, access reconciliation, security monitoring and change security review. The methods come from my work supporting SOX-aligned access and SoD controls on Oracle CC&B and SAP FI/CO at Exelon, federal security operations at the Social Security Administration, IAM investigations at AWS and access governance at CVS Health. The company, people and data are fictional, so every result can be published and rerun.

Work samples

SOX ITGC Control Testing Workpaper

Full-population tests of three IT general controls over billing and ERP: user access lifecycle, segregation of duties on 2,410 billing adjustments, and privileged and emergency access. Design and operating effectiveness, exceptions and remediation.

Shows: ITGC/SOX support · audit evidence · walkthrough support

Segregation of Duties Matrix for Financial Roles

Conflict rules across billing, receivables, general ledger and payables roles, with the conflicts found when the rules are run against every person's access across all of their accounts.

Shows: Access management · SoD for financial systems

Financial Application Access Reconciliation

Python reconciliation of 133 billing and ERP accounts against the HR roster and role catalog: terminated users, stale transfers, orphaned and second privileged accounts, and emergency grants.

Shows: Security risk assessment · control gap identification

Incident Case File: Self-Approved Billing Adjustments

From SIEM alert to root cause: 6 off-hours, self-approved adjustments ($48,300.00) traced to an emergency role grant with no expiry. Timeline, detection logic, containment and control fixes.

Shows: Security monitoring · investigation · root cause · escalation

Security Impact Review: Billing Platform Upgrade

Security review of a major billing-system upgrade: role mapping, SoD re-test, cutover privileged access, audit-log continuity, interface credentials and data conversion reconciliation, with go-live conditions.

Shows: Security SME on implementations · change request review

ITGC Risk & Control Matrix

Fourteen access, change and operations controls for financial applications, each mapped to the risk it addresses, its evidence and test procedure, SOX/COSO and NIST SP 800-53.

Shows: Control design · audit efficiency · security standards

Reproduce the results

Everything on this site is generated from the scripts in the repository, using only the Python standard library.

git clone https://github.com/Janaya-Hoskins/financial-systems-security.git
cd financial-systems-security
python scripts/generate_synthetic_data.py   # writes /data
python scripts/reconcile_access.py          # writes output/access_exceptions.csv
python scripts/sod_check.py                 # writes output/sod_*.csv
python scripts/incident_timeline.py         # writes output/incident_timeline.csv
python scripts/build_site.py                # rebuilds these pages

The same tests are written in SQL in sql/financial_controls_tests.sql, with a Splunk SPL version of the detection rule.

Northwind Holdings is a fictional company. Every person, account and transaction on this site is synthetic data generated by scripts/generate_synthetic_data.py. Nothing here is a record of any employer's systems, people or findings. · LinkedIn · Source on GitHub
